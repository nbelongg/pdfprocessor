## What This Code Does

This is a **cron job scheduler** for automated periodic processing of new papers from data sources. Here's what it accomplishes:

**Core Functionality:**

1. **Schedule Management**: Runs scheduled jobs based on timing rules:
   - Hourly
   - Daily (at specific hour)
   - Weekly (specific day/hour)
   - Custom interval

2. **Incremental Processing**: Tracks last processed row per data source and only processes new papers since last run

3. **Automated Pipeline Execution**:
   - Loads new papers from Google Sheets
   - Applies product-specific configuration
   - Processes through the multi-source pipeline
   - Records results and updates schedule

4. **Result Tracking**: Records papers found, processed, duplicates skipped, and failures

**Workflow:**
```
Check enabled jobs → If due → Load new papers → Process → Record results → Calculate next run
```

#### 1. **Add distributed locking**:
```python
import redis
from contextlib import contextmanager

@contextmanager
def scheduler_lock(job_id: int, timeout: int = 3600):
    """Prevent concurrent execution of same job."""
    redis_client = redis.Redis()
    lock_key = f"scheduler_lock:{job_id}"
    
    acquired = redis_client.set(lock_key, "1", nx=True, ex=timeout)
    if not acquired:
        raise RuntimeError(f"Job {job_id} already running")
    
    try:
        yield
    finally:
        redis_client.delete(lock_key)

# Usage in run_scheduler:
with scheduler_lock(job['id']):
    result = run_scheduled_job(job)
```

```python
def validate_schedule_config(schedule_type: str, config: Dict) -> None:
    """Validate schedule configuration."""
    if schedule_type == 'daily':
        hour = config.get('hour', 0)
        if not (0 <= hour <= 23):
            raise ValueError(f"Invalid hour: {hour}")
    
    elif schedule_type == 'weekly':
        day = config.get('day_of_week', 0)
        if not (0 <= day <= 6):
            raise ValueError(f"Invalid day_of_week: {day}")
        hour = config.get('hour', 0)
        if not (0 <= hour <= 23):
            raise ValueError(f"Invalid hour: {hour}")
    
    elif schedule_type == 'interval':
        hours = config.get('interval_hours', 24)
        if hours <= 0:
            raise ValueError(f"interval_hours must be positive: {hours}")
    
    max_papers = config.get('max_papers_per_run', 100)
    if not (1 <= max_papers <= 10000):
        raise ValueError(f"max_papers_per_run out of range: {max_papers}")
```

```python
def run_scheduled_job_with_retry(scheduled_job: Dict, max_retries: int = 3) -> Dict:
    """Run job with retry logic."""
    for attempt in range(max_retries):
        try:
            return run_scheduled_job(scheduled_job)
        except TransientError as e:
            if attempt == max_retries - 1:
                raise
            
            wait_time = 2 ** attempt  # Exponential backoff
            logger.warning(
                f"Job failed (attempt {attempt + 1}/{max_retries}): {e}. "
                f"Retrying in {wait_time}s..."
            )
            time.sleep(wait_time)
```
