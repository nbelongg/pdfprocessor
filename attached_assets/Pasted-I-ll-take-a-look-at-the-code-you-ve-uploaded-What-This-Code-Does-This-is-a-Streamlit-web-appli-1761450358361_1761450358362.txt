This is a **Streamlit web application** for a multi-tenant PDF processing and embedding pipeline. Here's what it accomplishes:

**Core Functionality:**
- **PDF Processing Pipeline**: Parses PDFs from Google Drive using LlamaParse, chunks the content, creates embeddings, and stores vectors in Pinecone
- **Multi-tenant Architecture**: Supports multiple products/startups with isolated credentials and separate Pinecone indexes
- **Job Queue Management**: Uses Celery for background processing of PDF jobs
- **Vector Search Testing**: Allows querying stored embeddings to test retrieval

**Key Features:**
1. **Product Management**: Create/manage multiple products with separate API keys and Pinecone indexes
2. **Data Source Management**: Connect Google Drive folders as data sources
3. **File Selection**: Choose specific PDFs to process
4. **Preview Chunks**: See how documents will be chunked before processing
5. **Job Queue**: Monitor processing jobs (pending/running/failed/completed)
6. **Processing History**: View past jobs and their results
7. **Search Interface**: Test vector similarity search on stored embeddings

**Technical Stack:**
- Streamlit for UI
- LlamaParse for PDF parsing
- OpenAI/HuggingFace for embeddings
- Pinecone for vector storage
- Database for tracking products, data sources, jobs, and chunks
- Celery for async job processing
